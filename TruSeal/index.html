工作原理

三步，把「原件」变成可核验的事实

签名是写入一份与内容哈希绑定的凭证，验签是重新计算哈希并核对签名。改动一个字节，结论就会翻转。

01

本地生成密钥

Ed25519 或 ECDSA P-256，私钥加密存放在你自己的电脑上，可导出公钥与证书交给合作方核对。

02

拖入文件，开始签名

支持 JPEG / PNG / MP4 / MOV。签名结果输出为副本，原文件保持不动，签名耗时通常在几毫秒。

03

任何人可离线验签

校验内容完整性、签名有效性与证书有效期，给出「可信 / 未知签名者 / 已篡改 / 无效」四态结论。
