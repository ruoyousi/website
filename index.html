合稿易

DocMerger

多人分工写，一键自动合

以「Word 模板 + Excel 数据」批量产出文档：模板引擎支持占位符、循环、表格、插入四类指令，另有文档合并、替换、目录抽取与图片提取五个子命令；桌面界面与命令行共用同一套实现。

业务价值

把重复排版与合稿从「天」压缩到「分钟」，一份模板对应一批交付文档；文档全程在本机处理，单文件分发、原生编译可免装 JRE。

心流写作

FlowWrite

本地优先的 AI 小说创作工作台

小说设定、大纲蓝图、逐章正文生成、定稿章节向量化入记忆库，后续写作自动检索前文注入；再配上去 AI 味润色与「AI 味指数」自检，构成完整创作闭环。

业务价值

把长篇创作最难的一致性维系交给向量记忆，角色、伏笔与时间线不脱节；小说与设定只留本地，不依赖云端账号。

OffOCR

离线文档解析

离线 OCR，隐私无忧

图片与 PDF 交给本地 OCR 服务，经版面分析与结构化识别，按阅读顺序还原标题、段落、表格、公式、图片与印章，导出 Markdown 与 Word；优先 CUDA，不可用自动回退 CPU。

业务价值

让涉密文档的数字化在本地闭环，文档不出设备、不上云，识别结果可直接进入编辑与归档流程；设备绑定授权适配涉密采购与合规审计。

Lovo

Voice Toolbox

本地语音工具，文本不出设备

语音合成、声音克隆、音色设计、语音识别四项能力齐备，覆盖 10 种合成语言与 30 种识别语言；命令行、桌面界面与 OpenAI 兼容 HTTP API 三种入口共用同一套本地模型。

业务价值

把语音能力做成可离线部署的基础设施：一次部署同时服务脚本、桌面与第三方系统，一句自然语言描述即可定制音色，无需录音棚素材。

Transly

lang-translator

数据主权在握的本地翻译

本地模型支撑 38 种语言、约 1056 个翻译方向，纯 CPU 推理无需显卡；内置术语库召回、翻译记忆预翻译、去翻译腔润色，以及准确性、术语、流畅性、风格四维质量评估。

业务价值

把「能翻译」升级为「译得准、译得一致」——术语与记忆沉淀为可复用资产，译文质量可评分、可追溯；内网、断网与野外环境同样可用。

FocusOn

个人工作台

记录你如何做事的个体工作台

四象限待办、个人记账、日历提醒、Markdown 笔记、习惯打卡、番茄专注、每日喝水与本地大模型对话八个模块；AI 可直接执行「新增待办、记一笔账、加日程」等意图。

业务价值

不存内容而记录行为，长期积累出可复盘的自我数据，让 AI 基于真实节奏给出方法建议；数据留在本机，离线可用。

画语

AI Prompt Helper

快速构建高质量 AI 绘画提示词

8 大类 33 条参考提示词库，配六个维度的可视化标签选择器，实时合成正向与负向提示词并一键复制；内置编写指导原则，支持中英双语与就地编辑。

业务价值

把提示词从「背口诀、反复试错」变成「选标签」，显著降低 Stable Diffusion / Midjourney 的入门门槛；配置数据可外部编辑，无需重新编译。
