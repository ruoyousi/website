CORE

四件核心的事，做到极致

不做大而全的平台，只把「陪伴」这一件事做完整。

VRM 3D 角色

三位内置角色开箱即用，支持导入你自己的 VRM 模型，动作与表情由角色自然演绎。

语音双向对话

说话即转文字，角色开口回应，嘴型随语音同步（viseme 驱动），像真人一样聊天。

本地优先

聊天记录、角色设定、配置全部存本地 SQLite；大模型可接本地 Ollama，全程离线可用。

长期记忆

对话自动记忆蒸馏，角色记得你们聊过的事，越聊越有默契，不用每次重新自我介绍。

FEATURES

功能清单

从角色定制到语音交互，全部可在设置面板里完成配置。

角色管理

内置角色 + 自定义角色自由增删；每个角色独立的人设、提示词、音色与语言，各聊各的互不串台。

导入自己的 VRM

选择本地 .vrm 文件即可导入为新角色，模型随应用一同加载，喜欢谁就带谁回家。

VoiceDesign 音色设计

用一句自然语言描述理想音色（如「甜美的少女音」），即可为角色定制专属声音，支持中英日韩等 10 种语言。

语音输入

按下麦克风直接说话，静音自动断句、本地转写成文字进入对话，不想打字时动动嘴就行。

口型同步

角色嘴型随语音实时驱动（viseme），配合动作系统，回复不再是「贴图说话」。

大模型可配

内置本地 Ollama 接入指引，也可填写任意 OpenAI 兼容接口地址与 API Key，流式输出随时中止。

对话历史管理

与每个角色的聊天独立存档，随时回看、继续或清空，上下文自动携带，续聊无缝衔接。

中英双语界面

界面文案内置中英两套词典，一键切换；角色回复语言亦可独立于界面语言单独设置。

本地优先，聊天是两个人的事

角色设定、对话历史、音色配置、许可证全部保存在本地 perch.db；大模型接本地 Ollama 时完全离线可用，全程不经过任何我们的服务器。改用云端接口时，也仅向你配置的厂商发送当前这一轮对话。
