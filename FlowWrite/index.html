CORE LOOPS

四个核心闭环，从零写到定稿

MVP 聚焦四件事，每一件都能闭环完成，不空转。

小说管理

小说、卷、章层级管理；角色卡与世界观的完整设定，生成时自动注入。

大纲与蓝图

AI 生成故事前提与主副线，一键生成整书分卷与各章蓝图，按结构创作而不自由发散。

正文生成 + 记忆

定稿章节自动向量化写入记忆库，后续生成检索相关前文，伏笔与设定不丢。

润色去 AI 味

口语化、节奏优化、对话拟人化模板；AI 特征自检输出 AI 味指数。

CAPABILITIES

为长期创作设计的细节

不止是生成，更关注前后一致性、可控性与可维护性。

流式正文生成

模型选择、温度、生成长度可调，结果流式输出、随时中止，可选注入设定 / 记忆 / 蓝图；生成、润色、自检提示词全部内置，无需手写。

本地 RAG 记忆层

定稿章节向量化入库，支持手动置顶关键设定、重建索引与检索测试，生成不脱离前文。

一键生成整书蓝图

前提与主副线就绪后，一键规划分卷与章节结构，自动建卷建章并逐章产出五要素蓝图。

AI 特征自检

检测模板化句式、高频词与过度解释，输出 AI 味指数（0–100）与逐条修改建议。

版本快照与差异对比

任意时刻存版本、填备注；选中两个版本对比新增与删除行，审稿不再怕改坏。

导出 TXT / Markdown

整书与单章一键导出，结构完整、格式正确，交付与备份都方便。

章节状态流转

草稿 → 润色中 → 审稿中 → 定稿；定稿即自动向量化写入记忆库，流程清晰可回退。

本地 Ollama / 云端任选

默认 http://localhost:11434/v1 离线生成；也可填任意 OpenAI 兼容云端地址与 API Key（智谱、小米等），Embedding 同样可上云。

本地优先，隐私是你的底线

小说、章节、角色、世界观、记忆、版本全部只存本地 SQLite；本地 Ollama 模式无需联网、不上传任何原文与设定，改用云端时仅向你配置的厂商接口发送当前生成所需的提示词。
