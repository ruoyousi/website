CORE

四件核心的事，做到极致

不堆功能，只把「把素材收拢到一处、且不让原稿冒险」这件事做完整。

无限画布空间

鼠标拖拽平移、滚轮缩放，画布没有边界；参考图、迭代稿、文字备注随手摆放，全局一眼尽览。

原图永不被改写

缩放、旋转、裁剪只把比例、角度、保留域写进节点，原图始终是唯一数据源，绝不覆盖、绝不产生中间文件。

纯本地运行，无任何网络请求；数据全留在本机，不上传、不依赖云端，断网也能照常开工。

多媒体混排

图片、文字、音频、视频节点同处一画布，自由拖拽、框选、分层；素材随取随用，思路不断档。

STUDIO

不止收纳，还能出片

内置多轨时间线剪辑器与全库资产面板——画布是素材的家，时间线是成片的路。

多轨时间线剪辑

视频轨 + 最多 5 条音频轨，片段拖动重排、按帧裁剪入出点、播放头实时预览；剪辑结果写回画布节点，导出全程本地完成。

资产库

自动汇集项目各级 .assets 全部素材（含未被画布引用的），面包屑目录 + 缩略图卡片浏览，双击即可上画布，子目录自由整理。

FEATURES

功能清单

从素材归集到导出分享，全部在本地完成，不需要账号、不需要联网。

素材自动归集

加入画布的图片一律复制进项目同级 .assets 目录，源文件移动或删除都不影响画布；只记相对路径，整个文件夹搬走也不丢图。

缩放·旋转·裁剪只记元数据

Resize 只改节点尺寸与比例，旋转只记角度，裁剪只记保留域——三步都不碰原图文件，可随时撤销/重做。

撤销 / 重做

所有编辑操作统一封装为可撤销命令，移动、复制、缩放、删除全覆盖，操作随时可回滚。

框选多选与图层

拖拽拉框批量选中节点，整体移动；置顶/置底/上下一层调整遮挡关系，重叠画面井然有序。

外部编辑自动刷新

在 Photoshop / GIMP 里改了原图，画布通过文件修改时间监听自动重新解码刷新，无需手动重开。

导出 ZIP 项目包

一键打包 .canvas 与全部引用素材为 ZIP，解压即是可直接打开的项目文件夹，备份分享两不误。

导出单图

选中单张图片即可导出 PNG / JPEG / WebP，导出内容含裁剪与旋转结果，原图不动。

明暗双主题 · 中英双语

界面内置明亮 / 暗黑两套主题，一键切换；中文 / English 文案随界面语言独立设置。

容错与缺失占位

图片被外部删除时显示占位框与路径提示，程序不崩溃；打开画布时自动校验格式版本与素材完整性。

纯文本画布文件

.canvas 是纯文本 JSON，只存节点属性与视口，不含图片二进制；支持外部脚本批量解析与处理。

语音合成与识别

内置 TTS / ASR 面板，接入你自己的本地语音服务即可文字转语音、语音识别；配音素材就地生成，无需第三方。

一键加水印

浮动工具栏一键给图片加水印，走本地 ffmpeg 处理，只记元数据不动原图。
